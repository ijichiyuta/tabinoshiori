# 旅のしおり

紙のしおりの記憶を持つデジタル。参加者は登録もログインもなく、URLを開くだけで
出欠の回答・行程・持ち物・連絡先をひとつの「しおり」で確認できるWebアプリ。

要件定義: `docs/旅のしおり-参加者UI.dc.html`(claude.ai/design で作成した全12画面のデザイン仕様)

## 起動

```sh
npm install
npm run dev        # 開発サーバー
npm run build      # 型チェック + 本番ビルド
npm run preview    # ビルド結果の確認 (http://localhost:4173)
```

トップページ `/` がデモの索引になっています。

## デモしおり

| slug | 種別 | 内容 |
|---|---|---|
| `tob2026` | グループ(12名) | バドミントンサークル 夏合宿 2026 三重・鳥羽。名簿・出欠・参加費集金あり |
| `kino2026` | 少人数(夫婦2名) | 城崎温泉 二泊三日。出欠なし、割り勘+精算+予約控えが主役 |

## 画面と機能

- **表紙** `/s/:slug` — タイポグラフィ表紙(推奨)/写真あり表紙(`?photo=1`)。更新告知バー、本人カード(次の集合・参加費・未払いバッジ)
- **本人選択** `/s/:slug/rsvp/who` — ログインの代わりに名簿から自分を選ぶ
- **出欠回答** `/s/:slug/rsvp` → `/rsvp/done` — 出欠・交通手段・参加費(PayPay送金はデモ)
- **行程** `/s/:slug/schedule` — 日タブ+タイムライン。当日は「いま」マーカーと進行中表示(デモ: `?now=2026-08-22T10:42`)
- **持ち物** `/s/:slug/items` — チェックリスト(端末に保存)
- **連絡先** `/s/:slug/contacts`(グループ)/ **費用と予約** `/s/:slug/costs`(少人数: 割り勘・精算・予約控え)
- **課金(幹事のみ)** `/publish/:slug` — 無料(6名まで・透かし入り)/1冊¥480買い切り/年間パス¥1,800 → 支払い → 公開・URL共有・領収書
- **印刷PDF** `/s/:slug/print` — A4しおり。無料プランは透かし入り

回答・チェック・支払い状態は localStorage に保存されます(サーバーなしのデモ実装)。

## 検証スクリプト

```sh
npm run preview -- --port 4173 &
node scripts/flow-test.mjs        # 主要フローのE2Eチェック(要 playwright-core)
node scripts/screenshot-demo.mjs  # 全画面のスクリーンショットを /tmp/shiori-shots へ
```

## デザインシステム

- アクセントは藍 `#2C4A7C` 一色。朱 `#C2452D` は「変更・警告・未払い」専用
- 見出し=Noto Serif JP(明朝)、本文=Noto Sans JP、数字は tabular-nums
- 影・グラデーションなし。区切りは 1px hairline のみ
