# バスツアー事業者向け要件定義(v1)

中小・大手バスツアー会社の悩み/要望を機能に落とし込む。個人利用(グループ/少人数)は従来どおり。

## 中小バスツアー会社(貸切バス・地域旅行会社)の悩みと対応機能

| 悩み・要望 | 実装する機能 |
|---|---|
| 集合時刻・乗車地の問い合わせ電話が多い | **乗車地(ピックアップポイント)**をしおりに登録。参加者は自分の乗車地だけが強調表示され、表紙に「あなたの集合」として時刻・場所・地図が出る |
| 参加者ごとに乗車地が違い、案内を間違える | 名簿に**乗車地・号車・座席**を割り当て。本人選択後は自分の号車・座席が表紙に出る |
| 当日の点呼(人数確認)が紙とペン | **点呼モード**(添乗員向け): 乗車地ごとの人数、ワンタップで乗車確認、未集合者と電話リンク |
| 集合変更・渋滞遅延の周知が電話連発 | 既存の**更新告知**(バナー+お知らせ一覧)をそのまま活用 |
| 高齢のお客様はアプリ登録で脱落する | 既存設計を維持: **URLを開くだけ・登録/ログイン不要・名簿から名前を選ぶだけ** |
| キャンセル規定・旅行条件の説明義務(旅行業法) | **案内ページ(旅行条件・キャンセル規定・FAQ)**。2023年改正の書面電子交付の受け皿 |
| 名簿の入力が手間(予約システムに既にある) | **CSV/タブ区切りの一括取り込み**(名前・乗車地・号車・座席・電話) |
| 同じコースを毎週催行する | **しおりの複製**(1クリックで次回催行分を作成) |
| 会社の信用・ブランドで案内したい | **催行会社(営業社名)・当日連絡先**をしおり全体に表示 |
| ツアー後の評判・改善点を知りたい | **アンケート**(5段階+自由記述、ツアー終了後に表紙へ表示)+ 集計画面 |

## 大手の追加要望と対応

| 要望 | 対応 |
|---|---|
| 大量催行・定型化 | 複製+テンプレート的運用(デモしおりを複製起点に) |
| 複数号車の運行 | 号車フィールド(1/2/…)、点呼は乗車地×号車で把握 |
| 予約システム連携 | CSV取り込み(将来: API連携はサーバー化後) |
| ブランド統一 | 催行会社表示+テーマ(きっちり/カジュアル)。ロゴ・色は将来のホワイトラベルで |
| 個人情報の扱い | 現状は端末内(localStorage)のみ。サーバー化時に委託契約・削除規定とセットで対応 |

## 参加者(乗客)体験の設計

1. 予約時に案内されたURL/QRを開く → 名簿から自分の名前を選ぶ(検索付き)
2. 表紙に「あなたの集合 7:10 名古屋駅」「2号車 12A」が出る
3. 行程タブ: 乗車地一覧(自分に「あなた」チップ)+ 当日は「いま」マーカー
4. 案内タブ導線: 持ち物/キャンセル規定/FAQ/当日連絡先
5. ツアー終了後: アンケートのお願いが表紙に出る

## 今回のスコープ外(サーバー化後)

- 複数端末の名簿・点呼同期、スタッフ権限、予約API連携、ロゴ入りホワイトラベル、多言語
